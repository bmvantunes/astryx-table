# 11. Row and range selection with atomic copy

## What to build

Client row selection and identity-stable linear ranges copy safely across virtual windows.

## Acceptance criteria

- [ ] Preserve raw Client row identities, Shift anchor and grouped-view selection restrictions; Server remains Active-Cell-only.
- [ ] Retain exact selected row/column spans and invalidate only on semantic shape changes.
- [ ] Capture one immutable canonical clipboard snapshot with draft/overlay precedence; live publications cannot mix payload versions.
- [ ] Test pinned/RTL/virtualized selection, grouped copy and clipboard failures.

## Blocked by

- Draft ticket 3: Pinned, RTL, resize and reorder parity
- Draft ticket 4: Keyboard and recycled-focus parity
- Draft ticket 6: Read-only Client grouping
