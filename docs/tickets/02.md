# 2. Virtual read-only Client with Astryx theme and menu

## What to build

A real read-only Client grid with explicit identities, initial sorting, two-axis windowing and a published Astryx header menu.

## Acceptance criteria

- [ ] Preserve one scroll owner, bounded row/column mounts, stable row references and root-render isolation.
- [ ] Demonstrate theme tokens and a menu through supported Astryx anchors/focus APIs; no surrogate trigger inherited blindly.
- [ ] Prove StyleX application and library CSS extraction and installed-consumer behavior with a non-empty renderer.
- [ ] Retain source/type and public Browser tests for empty/large data and immutable publications.
